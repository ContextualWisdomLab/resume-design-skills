# 이력서 디자인 작업표

작업 기록에 사용하고 제출본에는 넣지 않는다.

| 항목 | 기록 |
| --- | --- |
| 원본 파일과 최종 파일 | 파일명과 버전 |
| 독자와 지원 직무 | 공고나 사용자가 확인한 범위 |
| 문서 유형 | 일반 이력서 / 경력자 이력서 / 경력기술서 / 학술 CV / 지정 양식 |
| 제출 조건 | 형식, 용량, 용지, 쪽수, 필수 필드 |
| 고정 조건 | 표·행열·병합·항목명·서명·사진 영역 등 |
| 편집 범위 | 서식만 / 내용 편집 포함 |
| 사실 대조 | 회사명, 직책, 기간, 겸직, 학력, 숫자·단위·조건 |
| 정보 순서와 페이지 계획 | 각 페이지의 시작·끝, 경력 연결 |
| 서체와 간격 | 실제 설치 글꼴, 크기, 여백, 문단 간격 |
| 렌더 검수 | 도구·버전, 파일, 실제 쪽수, 전 페이지 확인 여부 |
| 텍스트·링크 검수 | 누락, 순서, 표 셀 연결, 링크 표시값과 대상 |
| 별도 검증 | 글꼴 포함, 태그·스크린리더, 실제 ATS: 수행 / 미실시 |
| 남은 확인 | 미실시 항목과 사용자에게 필요한 조치 |

`확인`, `경고 후 수동 확인`, `미실시`를 구분한다. 원본이 없으면 내용 보존을 확인했다고 기록하지 않는다.
