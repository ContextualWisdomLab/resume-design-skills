# 이력서 디자인 스킬 설계

## 목적

이력서의 사실과 제출 조건을 보존하면서 경력, 역할, 성과를 찾기 쉬운 문서를 만든다. 공개 스킬은 일반적인 직무에 적용하고, 팀장급 이력서와 경력기술서의 내용 작성은 기존 ContextualWisdomLab 스킬에 연결한다.

## 설계 결정

- `resume-design` 한 개를 배포한다. `SKILL.md`에는 분기와 작업 순서를, `references/`에는 출처, 디자인 수치, 지정 양식과 검수 방법을 둔다.
- 자유 형식의 일반 이력서, 경력자 이력서, 회사 지정 양식을 구별한다. 지정 양식은 구조와 필수 항목을 유지한다. 학술 CV의 분량은 이력서 규칙으로 제한하지 않는다.
- 기관 권고, 제품 문서, 이 프로젝트의 디자인 기본값을 구분한다. 채용 성과, ATS 통과율, 모든 문서의 최적 쪽수를 주장하지 않는다.
- 재사용 도구는 읽기 전용 DOCX 사전 검사와 합성 예제 생성기로 제한한다. 외부 ATS 업로드, 외부 분석 서비스, 네트워크 호출은 하지 않는다.
- DOCX의 글자·표·문단 구조 검사와 PDF의 렌더 검사를 서로 다른 증거로 기록한다. 모든 페이지를 검토하고 최종 텍스트의 순서·핵심 수치를 확인한다.
- 공개 예시는 합성 인물·회사·수치만 사용한다. 사용자 경력, 연락처, 채용 서류, 메일을 포함하지 않는다.
- 원본 템플릿의 코드는 복사하지 않는다. 자체 작성한 자료에 MIT License를 적용하고 외부 자료는 출처와 확인 범위를 남긴다.

## 산출물과 검증

설치 가능한 스킬, 출처 장부, 디자인 규칙, 지정 양식 보존 절차, DOCX 사전 검사기, 1쪽 일반 이력서와 2쪽 경력자 이력서의 합성 예시를 제공한다. 검사기는 내용 유실과 구조상 위험 신호를 찾는 기능을 실제 입력으로 시험한다. 에이전트 적용 시나리오와 각 예제의 모든 페이지 렌더 검토 결과를 기록한다.
